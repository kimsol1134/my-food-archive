# 6~14장 · Android 앱 만들기

Mac 또는 Windows에서 Android 앱을 만드는 독자를 위한 보충 안내입니다. 책의 현재 장을 먼저 읽고, 아래에서 달라지는 부분을 확인합니다. Google Play 배포는 15장부터 시작합니다.

## 개발 준비

| 책 | Android에서 확인할 것 | 끝나면 |
|---|---|---|
| 6장 | Windows는 본문의 PowerShell·Git for Windows 안내, Mac은 터미널 안내를 따릅니다. 프로젝트의 docs 폴더에는 직접 만든 공통 문서와 TRD_android.md를 넣습니다. | 7장으로 갑니다. |
| 7장 | TRD_android.md를 기준으로 Implement_plan_android.md를 만들고 Task 1을 진행합니다. | 8장으로 갑니다. |
| 8장 | Android 문서 두 개를 기준으로 권한·테마·저장·상태 관리를 구현합니다. | 아직 완성 화면이 없어도 9장에서 연결합니다. |
| 9장 | Android Studio와 Android 에뮬레이터를 준비합니다. Xcode와 iOS 시뮬레이터 단계는 Android 안내로 대신합니다. | 앱 실행과 화면 이동을 확인하고 10장으로 갑니다. |

막히면 프로젝트 폴더에서 클로드 코드에게 다음과 같이 요청합니다. 대괄호 부분은 자신의 환경으로 바꿉니다.

```text
나는 [Mac 또는 Windows]에서 Android 앱을 만들고 있어.
지금 책 [장과 절]을 진행하고 있어.
docs/TRD_android.md와 docs/Implement_plan_android.md를 읽고,
현재 단계에 필요한 설치와 설정이 준비됐는지 확인해 줘.
이미 설치된 도구는 먼저 버전을 확인하고, 빠진 작업만 순서대로 알려줘.
앱을 실행할 때는 Android 에뮬레이터를 사용해 줘.
오류: [화면의 오류 문장]
```

## Firebase 연결

**10.1~10.2절에서 연결을 준비하고 11장에서 AI 자동 입력을 확인합니다.** Firebase 프로젝트 생성과 AI Logic 활성화는 책의 공통 설명을 따릅니다. Apple 앱 등록 화면은 실행하지 않고, 책의 Android 분기에 따라 클로드 코드에게 Android 앱 등록과 Flutter 연결을 맡깁니다.

```text
나는 Android 앱으로 책 10.2절을 진행하고 있어.
내 Firebase 프로젝트 ID는 [내 프로젝트 ID]야.
현재 Android 패키지 이름을 먼저 확인하고,
이 프로젝트에 맞게 Firebase 연결과 App Check 개발용 설정을 진행해 줘.
저자 예시의 프로젝트 ID나 앱 식별값을 사용하지 마.
콘솔에서 내가 직접 할 일과 성공 확인 방법을 한 단계씩 알려줘.
비밀번호나 디버그 토큰을 대화창에 붙여넣도록 요청하지 마.
```

클로드 코드가 안내한 위치에서 디버그 토큰을 확인하고, 자신의 Firebase 콘솔에 직접 등록합니다. 이 토큰은 공개 저장소나 문의 글에 올리지 않습니다.

- 10장 완료: 사진을 선택하면 입력 화면이 열립니다. 날짜·위치 정보가 없는 사진은 해당 칸이 비어 있을 수 있습니다.
- 11장 완료: 음식 사진으로 메뉴·카테고리 자동 입력을 확인합니다. 사진을 읽는 것과 AI 연결이 성공하는 것은 별개입니다.
- AI 입력만 실패: 네트워크, 선택한 Firebase 프로젝트, Android 앱 등록, App Check 개발용 토큰을 확인합니다. Firebase 콘솔의 설정과 앱 실행 로그를 함께 확인하도록 클로드 코드에 요청합니다.

## 저장부터 통합 확인까지

12~14장은 본문의 작업 순서를 그대로 따르되, 프롬프트에 Android용 TRD와 구현계획서를 기준으로 작업하라고 덧붙입니다.

1. 사진과 식당명을 저장하고 앱을 다시 열어 기록이 남는지 확인합니다.
2. 지역·메뉴 검색, 수정, 사진 재선택, 삭제를 확인합니다.
3. AI 연결이 실패해도 직접 입력해서 저장할 수 있는지 확인합니다.
4. 에뮬레이터의 사진 선택 화면과 권한 안내가 책의 iPhone 화면과 달라도, 요청한 기능이 되는지 기준으로 확인합니다.

14장을 마치면 [Google Play 내부 테스트](google-play-internal-test-guide.md)로 이동합니다. 배포용 Play Integrity 설정은 그 가이드에서 진행합니다.
