# Google Play 기본 스토어 등록정보

## 앱 이름

My Food Archive

## 간단한 설명

사진 한 장으로 메뉴와 카테고리를 자동 정리하는 나만의 맛집 아카이브

## 자세한 설명

음식 사진 한 장으로 맛집 기록을 간편하게 남기고 다시 찾는 개인 아카이브 앱입니다.

오늘 먹은 음식과 마음에 든 식당을 사진첩 속에 묻어두지 마세요. My Food Archive는 사진, 메뉴, 식당명, 지역과 날짜를 한곳에 모아 나만의 맛집 기록으로 정리해 줍니다.

■ 사진에서 메뉴를 자동 분석
갤러리에서 음식 사진을 고르면 Google Gemini AI가 메뉴 이름과 음식 카테고리(한식·중식·일식·양식·카페/디저트 등)를 분석해 입력합니다. 분석 결과는 저장 전에 자유롭게 수정할 수 있습니다.

■ 촬영 날짜와 지역 정리
사진에 포함된 EXIF 촬영 날짜와 위치 정보가 있으면 날짜와 지역을 자동으로 채웁니다. 실시간 위치를 추적하거나 위치 권한을 요청하지 않습니다.

■ 내 기기에 보관되는 맛집 기록
식당명, 메뉴명, 카테고리, 날짜, 지역과 저장한 사진은 앱 전용 저장 공간에 보관됩니다. 회원가입이나 로그인이 필요하지 않습니다. 사용자가 선택한 사진은 메뉴와 카테고리 분석을 위해 Firebase AI Logic을 거쳐 Google Gemini로 전송될 수 있습니다.

■ 빠른 검색
식당 이름, 메뉴, 카테고리와 지역을 조합해 저장한 기록을 바로 찾을 수 있습니다.

■ 간단한 수정과 삭제
저장한 기록을 수정하거나 필요 없는 기록과 연결된 사진을 함께 삭제할 수 있습니다.

■ 광고와 사용자 추적 없음
광고를 표시하지 않으며 광고 목적의 사용자 추적을 하지 않습니다.

좋아하는 음식을, 좋아했던 순간 그대로 모아보세요.

## 데이터 보안 답변 초안

- 앱이 사용자 데이터를 수집하거나 공유하는가: 예
- 사진: 수집함, 앱 기능 목적, 필수, 일시 처리로 표시
- 앱 활동/사용자 입력 기록: 별도 수집 안 함
- 정확한 위치: 수집함, 앱 기능 목적, 선택사항, 일시 처리로 표시. 위치 권한이나 실시간 위치는 수집하지 않지만 사용자가 고른 사진의 EXIF 위치 메타데이터가 전송될 수 있음
- 기기 또는 기타 ID: 수집함, 사기 방지·보안·규정 준수 목적, 필수. Firebase App Check와 Play Integrity가 앱 보호를 위해 처리
- 광고 목적: 없음
- 사용자 추적: 없음
- 전송 중 암호화: 예
- 데이터 삭제 요청: 계정 없음. 앱 안에서 개별 기록 삭제 가능하며 앱 삭제 시 로컬 데이터 제거
